# Сайты из markdown
Одна разметка для терминала и браузера. Ноль зависимостей.
:::

::: grid 3
::: card Блоки страницы
Секции, карточки, сетки и колонки — прямо в markdown.
:::

::: card Живые данные
Счётчики, часы и прогресс обновляются без перезагрузки.
:::

::: card Один источник
И `node md-ui.js`, и браузер читают один AST и одно состояние.
:::
:::

::: banner Готово green
Соберите сайт командой `node md-ui.js build docs -o site`.
:::
