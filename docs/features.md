# Возможности

::: section Блоки страницы
Тело блока — обычный markdown: **жирный**, *курсив*, `код`, [ссылки](widgets.md).
:::

::: cols
### Слева
Колонки делятся строкой `---`.

---

### Справа
Каждая колонка — полноценный markdown.
:::

::: card Код
```js
function привет(имя) {
  return `Привет, ${имя}!`;
}
```
:::

::: card Доступность
Все виджеты размечены ARIA-ролями, у страницы есть skip-link и `<main>`.
Управление доступно с клавиатуры.
:::

::: card Светлая тема
Включите директивой `::: theme light` или полем `theme: light` во frontmatter.
:::
