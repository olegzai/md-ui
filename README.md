# md-ui

**Markdown с интерактивными виджетами — одна разметка, два вывода: терминал и браузер.**

Без единой зависимости: собственный парсер markdown + виджеты, два рендера
(ANSI для терминала и семантический HTML для веба), общее состояние (`vars`)
для «живых» данных. Он же — CLI, веб-сервер и редактор с live-preview в одной
крутке файла.

## Быстрый старт

```sh
node md-ui.js                 # терминальный редактор demo/demo.md (Ctrl+Q — выход)
node md-ui.js serve 8123      # веб-сервер → http://localhost:8123/demo
node md-ui.js convert doc.md  # печатает HTML (тот же, что в браузере)
node md-ui.js convert doc.md --body   # только содержимое body
node md-ui.js build docs -o site      # собрать статический сайт из каталога
node md-ui.js build docs -o site --watch   # то же, с пересборкой на лету
node md-ui.js serve 8080 site         # раздать готовый сайт локально
node md-ui.js doc.md --ascii  # ASCII-режим для простых терминалов
```

TUI: `Tab` — фокус на виджете, `Enter`/`Space` — действие, `1..9` — быстрый
переход, `R` — Preview ⇄ HTML, `Ctrl+K` — вставка символов, `Ctrl+S` — сохранить,
`Ctrl+Q` — выход.

Тесты: `node --test` (проверяют и терминальный, и веб-рендер).

## Базовый markdown

Поддерживается привычное: заголовки `#`–`######`, `**жирный**`, `*курсив*`,
`__подчёркивание__`, `` `код` `` инлайн, блочный код ````` ``` `````,
Цитаты `>`, списки `-`/`*`/`1.` и чекбоксы `- [x]`, таблицы `| ... |`,
разделители `---`, ссылки `[текст](https://…)`, картинки `![alt](src)`,
frontmatter `---…---`.

## Уникальная авторская разметка

Всё строится из двух простых синтаксических форм:

1. **Инлайн-виджет** — `{Текст}` прямо внутри строки.
2. **Блок-виджет** — `::: тип подпись [стиль]` отдельной строкой.

Псевдокод:

```text
::: <тип> <подпись или данные> [ <стиль> ]
{Инлайн-виджет}
```

### Инлайн-виджеты

| Разметка | Виджет | TUI | Веб |
| --- | --- | --- | --- |
| `{Запустить}` | кнопка | фокус → Enter = нажать | кнопка, клик |
| `{Запустить green}` | кнопка со стилем | обрамляется `[*]` | цветная кнопка |
| `{@score}` | **живая переменная** | значение из `vars`, обновляется | значение, обновляется |

```md
Нажми {Запустить}, чтобы начать. Очки: {@score}.
```

### Блок-виджеты

| Разметка | Виджет | Что делает |
| --- | --- | --- |
| `::: button Запустить green` | кнопка (alias `btn`) | как `{...}` |
| `::: fold Подробнее` | складка (alias `details`) | тело до `:::` прячется/раскрывается |
| `::: bar 70` | прогресс (alias `progress`) | полоса, значение 0–100 |
| `::: bar @score` | **живой прогресс** | полоса читает переменную `score` |
| `::: tabs Игра / Музыка / Книги` | вкладки (alias `tab`) | ` / ` разделяет вкладки |
| `::: select красный / зелёный` | выбор | переключение опций |
| `::: input Твоё имя` | поле ввода | ввод текста (пока не связано с `vars`) |
| `::: tree Игрушки / Гоночки / Машинки` | дерево (alias `menu`) | вертикальный список |
| `::: modal Точно удалить?` | вопрос-модалка | Enter — да, Esc — нет |
| `::: note Примечание` | заметка | выделенный блок |
| `::: warn Осторожно` | предупреждение | выделенный блок |

### Блоки страницы (строительные кирпичи сайтов)

Тело — обычный markdown до первой строки-закрывателя `:::`.

| Разметка | Что даёт |
| --- | --- |
| `::: section О проекте` | смысловая секция `<section>` с заголовком |
| `::: card Пример` | карточка с рамкой (alias `widget`) |
| `::: hero Главный экран` | крупный баннер-заголовок |
| `::: nav` | навигация (ссылки внутри — элементы меню) |
| `::: footer` | подвал страницы |
| `::: banner Ок green` | цветная плашка-уведомление (стили green/red/blue/yellow/primary/big) |
| `::: grid 2` | сетка из N колонок (1–12), адаптивная на узких экранах |
| `::: cols` | две колонки, разделитель колонок — строка `---` внутри тела |
| `::: img logo.png Логотип` | блочная картинка с подписью |

```md
::: section О проекте
Текст секции, внутри можно любую разметку и виджеты.
:::

::: grid 2
Первая ячейка.

Вторая ячейка.
:::

::: cols
Левая колонка.

---

Правая колонка.
:::
```

### Картинки и ссылки

```md
Лого: ![md-ui](logo.png)                 # инлайн-картинка с alt и подписью
::: img hero.png Главный экран            # блочная картинка

[Внешний сайт](https://example.com)       # откроется в новой вкладке
[Страница сайта](about.md)                # внутренняя ссылка, без новой вкладки
```

Внутренние ссылки на `.md`-файлы в собранном сайте превратятся в `.html`.

### Frontmatter, тема и свой CSS

В начале файла можно объявить метаданные `title`, `description` и т.п. —
блок отделяется `---` и пропускается при рендере:

```md
---
title: Моя страница
description: Короткое описание для поисковиков
---
```

Переключение темы и добавление своего CSS:

```md
::: theme light        # dark (по умолчанию) / light
::: css
h1 { color: rebeccapurple; }
:::
```

CSS-блок попадает в `<head>` страницы и может переопределять любые стили.

### Включение файлов (include)

Разметку можно собирать из частей — содержимое включается в исходник до рендера:

```md
::: include parts/header.md
:::
```

Резолвится относительно файла, защищено от циклов; в случае ошибки вместо кода
появляется предупреждение.

### Живые данные (это и есть «фишка» проекта)

Отдельный слой состояния `vars` живёт одновременно в терминале и в браузере —
оба рендера читают и меняют один и тот же объект.

| Разметка | Смысл |
| --- | --- |
| `::: var score 42` | объявить переменную `score = 42` (не рендерится) |
| `::: var score` | объявить без начального значения (`""` или `0`) |
| `::: clock` | текущее время HH:MM:SS, тикает каждую секунду |
| `::: counter score` | счётчик: Enter/пробел в TUI, `−`/`+` в вебе — меняет `score` |
| `::: bar @score` | полоса показывает `score` (0–100) |
| `{@score}` | подставить текущее значение прямо в текст |

```md
::: var score 7

## Живая метрика

Время: ::: clock
Очки:  {@score}
::: counter score
Прогресс: ::: bar @score
```

Любой виджет, который меняет переменную (счётчик, кнопка), мгновенно обновляет
все `{@name}` в тексте и все `::: bar @name` — и в терминале, и в браузере.

### Стили

Применяются к кнопкам и прогресу: `green`, `red`, `blue`, `yellow`, `big`,
`dim`, `primary`.

```md
::: button Запустить green
::: button Стоп red
::: button Пауза big
::: bar 70 big
```

### Разделители и серии

` / ` внутри одной строки — разделитель опций (tabs/select/tree):

```md
::: tabs Игра / Музыка / Книги
```

## Данные и графики

`::: source` подключает данные из JSON-файла (путь относительно документа) или
по URL. `::: data` рисует таблицу, `::: chart` — горизонтальную диаграмму.
Ключи объектов становятся колонками; последняя колонка используется как
значение для графика.

```md
::: source cities _data/cities.json

::: data cities

::: chart cities
```

Локальные файлы читаются при `build`/`convert` и встраиваются в HTML — страница
работает офлайн, без JS. Для URL источник подгружается в браузере во время
исполнения. В терминале таблица и диаграмма рисуются символами.

`::: every 3s` оборачивает блок и заставляет браузер перечитывать источники
каждые N секунд:

```md
::: every 3s
::: clock
:::
```

## Сборка сайта

`build` превращает каталог с `.md` в готовый статический сайт: страницы
становятся `.html`, внутренние ссылки `[о нас](about.md)` переписываются в
`about.html`, копируются ресурсы (картинки, css), генерируются `index.html`,
`404.html`, подключается `site-runtime.js` (оживляет виджеты без зависимостей).

```sh
node md-ui.js build docs -o site                    # из docs/ в site/
node md-ui.js build docs -o site --base https://example.com
node md-ui.js build docs -o site --watch            # пересборка при изменениях
node md-ui.js serve 8080 site                       # локальный просмотр
```

Что попадает в `<head>` каждой страницы:

- `<title>` и `<meta name="description">` из frontmatter;
- Open Graph и Twitter Card (`og:title`, `og:description`, `og:type`);
- `lang` из frontmatter (`lang: ru`);
- `canonical` при указании `--base`;
- тема и ваши `::: css` прямо в разметке.

При `--base` дополнительно пишутся `sitemap.xml` и `robots.txt`.

**Фрагменты** — файлы и каталоги, начинающиеся с `_`, не становятся страницами
и используются только через `::: include`. Это удобно для общего меню и подвала:

```md
::: nav
::: include _parts/nav.md
:::
```

Сгенерированный сайт полностью читается и без JavaScript (контент
предрендерен в HTML); скрипт лишь «оживляет» счётчики, часы, модалки и вкладки.

## Архитектура

```text
Markdown + разметка
        │
        ▼
   parseBlocks / parseInline   → AST (узел widget — тип, подпись, стиль, value, name)
        │
        ├── collectWidgets  → порядок виджетов (порядок фокуса в TUI)
        ├── collectVars     → переменные состояния
        │
        ├── renderANSI      → терминал  (фокус, хоткеи, тикер 1 с)
        ├── widgetHTML      → браузер   (события, тикер 1 с)
        └── refreshSource   → st = { ast, widgets, vars }
```

Ключевое свойство: **индексы виджетов совпадают** в терминале и в вебе, поэтому
«одна запись → один и тот же интерфейс» достигается без переписывания логики.
